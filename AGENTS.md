# AGENTS.md

This file provides guidance for AI agents and automated tools working with this repository.

## Project

Enote — digital delivery notes for Xiera Bakery, Ocotlan, Jalisco. Multi-user SPA with status workflow. Vanilla JS, no framework. Supabase backend + Vercel hosting.

**Version:** 1.3.7 | **URL:** https://enote-xiera.vercel.app

## Quick Start

```bash
node scripts/build-config.js   # Generate js/supabase.js from .env (REQUIRED before serving)
npx serve .                    # Dev server
npx vercel --prod              # Deploy
```

**Env vars:** `SUPABASE_URL`, `SUPABASE_ANON_KEY` (set in Vercel or `.env`). See `.env.example`.

## Architecture

Entrypoint: `index.html` → `js/app.js` (ES module orchestrator, no bundler, no framework).

```
js/
  app.js              Orchestrator: global state, event delegation, pagination, safeHandler
  config.js           Constants: roles, statuses, locations, PAGE_SIZE=20, BUSINESS_INFO
  store.js            Supabase CRUD, validateNoteFields, conflict detection, handleApiError
  auth.js             Supabase Auth, permission helpers, canModifyNote
  offline.js          IndexedDB: IMAGE_CACHE (FIFO, limit 500) + PENDING_QUEUE (scoped by _userId)
  logger.js           Event logger → POST /api/log
  imageUtils.js       compressImage → WebP 40% via Canvas, MAX_IMAGES_PER_NOTE = 3
  types.js            JSDoc @typedef (Note, Session, Role, Product, ImageRef)
  vendor/supabase-js.esm.js   Self-hosted Supabase JS client v2 (44 KB, no CDN)
  supabase.js         GENERATED by build-config.js (gitignored — never edit)
  supabase.js.template   Template with __SUPABASE_URL__ / __SUPABASE_ANON_KEY__ placeholders
  ui/shared.js        esc(), showView(), openModal/closeModal (revokes blob URLs), formatFecha (UTC)
  ui/login.js         Login view (Supabase email + password)
  ui/dashboard.js     Note grid, filters, client-side pagination
  ui/form.js          Create/edit form
  ui/detail.js        Detail, diff, conflict, delete confirm — uses detail-overlay, NOT showView()
  ui/repartidor.js    Driver view (toggle tomada)
  ui/print.js         Printable receipt

assets/fonts/        Self-hosted fonts (Inter, Material Symbols) — no CDN fonts
icons/               PWA icons (192, 512, maskable)
scripts/build-config.js     Generates js/supabase.js + injects ENOTE_VERSION into sw.js
scripts/pw-verify.js       Post-deploy PWA + config verification
scripts/generate-icons.js  PWA icon generator from SVG
vercel.json          Build config, CSP headers, cache rules
sw.js                Service Worker — ENOTE_VERSION injected by build-config.js
offline.html         Offline fallback page
robots.txt           User-agent: * Disallow: /
```

## Key Patterns

### Error handling
- `window.onerror` + `unhandledrejection` in `app.js` — toast + `log.error()`
- `safeHandler(fn)` wraps all UI event handlers (dashboard, detail, repartidor, modal)
- `handleApiError()` in `store.js` maps Supabase codes: 401/PGRST301/42501 → fires `enote:auth-expired`
- `init()` catches non-auth errors and shows fallback dashboard

### RBAC (defense in depth)
- `canModifyNote()` in `auth.js` — checks role + note ownership
- `updateNote`/`deleteNote` in `store.js` validate permissions before server call
- UI guards: `canCreate`, `canEdit`, `canDelete` in all handlers

### Offline (IndexedDB v3)
- `IMAGE_CACHE`: keyPath `url`, FIFO eviction via `cachedAt` (limit 500)
- `PENDING_QUEUE`: scoped by `_userId`, transient `_session` stored per item
- `_syncing` guard prevents concurrent syncs
- `openDB()` with `onblocked`, `onversionchange`, `onclose` for multi-tab safety
- Transactions resolve on `tx.oncomplete` (atomic)
- `cacheImages` with `AbortController` + 10s timeout per batch
- `logout()` calls `clearAllOfflineData()` to remove PII residue

### Service Worker
- Versioned cache: `enote-` + `ENOTE_VERSION` (from build-config.js)
- Install: `fetch({cache:'reload'})` bypasses HTTP cache for fresh content
- `skipWaiting()` + `clientsClaim()` on install
- Stale-while-revalidate for navigation
- `controllerchange` listener in `index.html` auto-reloads on new SW activation
- `_sw_reloading` flag in sessionStorage prevents infinite reload loop; cleared in `init()`

### Conflict detection
- `updateNote` receives `_localModifiedEn` from `editingNoteModifiedEn`
- If server's `modificadoEn` is newer → `{ conflict, serverNote }` → `renderConflictView`
- Overwrite button re-calls with `_force: true`; keep-server button discards local changes

### Template conventions
- All HTML as template strings, no JSX
- All user input escaped via `esc()` (includes `'` → `&#39;`)
- Dates: ISO in store, `es-MX` in UI, `formatFecha()` uses UTC to prevent timezone day shift
- Falsy-safe: `pastelCantidad`/`pisos` use `!= null` not `||` defaults (0 is valid)

### Blob URL lifecycle
- URLs created by `compressImage` tracked in `_blobUrls` array
- `revokeBlobUrls()` in `closeModal()` runs before DOM clear
- `showImagePreview` also tracks preview blob URLs

### Detail view
- Does NOT use `showView()`. Uses `detail-overlay-active` class + `display: block` to overlay on dashboard.
- `currentDetailNoteId` tracks open detail for image preview.
- `planta` role auto-transitions `Nueva → En Proceso` on detail open, using `_force: true`.

### Pagination & filters
- Client-side. `getBaseNotes()` (role/destino filter) → `getFilteredNotes()` (UI filters) → `slice` by page.
- Reset to page 1 on filter change. Debounce search: 280ms.
- `pendingFormData` is a third state in `app.js` for diff/conflict flow: `{ noteId, fields, action }`.

### Numbering
- Note `numero`: `MAX(numero) + 1`, formatted `#0001`. Race condition accepted for current volume.

### CSP & caching
- No external CDNs allowed (`script-src`, `style-src`, `font-src` all `'self'`)
- Fonts self-hosted in `assets/fonts/`; Supabase JS client vendored in `js/vendor/`
- `/js/supabase.js` → `no-cache, must-revalidate` (overrides generic JS immutable rule)
- Other JS/CSS → `max-age=31536000, immutable`

## Testing

```bash
cd audit && npm install          # First time only
node audit-offline.js [URL]      # Offline suite (IndexedDB, queue, badge, fallback)
node audit-prod.js [URL]         # Production suite (3 roles, CRUD, offline, PWA, a11y)
node audit-v2.js [URL]           # v2 suite (pasteleria, financiero, receipt, conflict)
node scripts/pw-verify.js [URL]  # PWA and config verification
```

**Note:** `audit/audit.js` is obsolete (uses demo credentials, exits immediately). Use `audit-prod.js` or `audit-v2.js`.

## Status workflow

```
Nueva → En Proceso → Completada / Cancelada
        │
        └── (planta auto-transitions Nueva→En Proceso on detail open)
```

## Adding users

1. Supabase → Authentication → Users → Add user
2. Copy UUID
3. SQL: `INSERT INTO profiles (id, username, role, destino) VALUES ('<uuid>', 'name', 'role', 'destino|null')`
