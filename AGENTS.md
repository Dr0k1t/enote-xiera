# AGENTS.md

This file provides guidance for AI agents and automated tools working with this repository.

## Project

Enote — digital delivery notes for Xiera Bakery, Ocotlan, Jalisco. Multi-user SPA with status workflow. Vanilla JS, no framework. Supabase backend + Vercel hosting.

**Version:** 1.3.2 | **URL:** https://enote-xiera.vercel.app

## Quick Start

```bash
node scripts/build-config.js   # Generate js/supabase.js from .env (REQUIRED before serving)
npx serve .                    # Dev server
npx vercel --prod              # Deploy
```

**Env vars:** `SUPABASE_URL`, `SUPABASE_ANON_KEY` (set in Vercel or `.env`). See `.env.example`.

## Key Patterns

### Error handling
- `window.onerror` + `unhandledrejection` in `app.js` — toast + `log.error()`
- `safeHandler(fn)` wraps all UI event handlers (dashboard, detail, repartidor, modal)
- `handleApiError()` in `store.js` maps Supabase codes: 401/PGRST301/42501 → fires `enote:auth-expired`
- `init()` catches non-auth errors and shows fallback dashboard

### RBAC (defense in depth)
- `canModifyNote()` in `auth.js` — checks role + note ownership
- `updateNote`/`deleteNote` in `store.js` validate permissions before server call
- UI guards: `canCreate`, `canEdit`, `canDelete` in all handlers

### Offline (IndexedDB v3)
- `IMAGE_CACHE`: keyPath `url`, FIFO eviction via `cachedAt` (limit 500)
- `PENDING_QUEUE`: scoped by `_userId`, transient `_session` stored per item
- `_syncing` guard prevents concurrent syncs
- `openDB()` with `onblocked`, `onversionchange`, `onclose` for multi-tab safety
- Transactions resolve on `tx.oncomplete` (atomic)
- `cacheImages` with `AbortController` + 10s timeout per batch
- `logout()` calls `clearAllOfflineData()` to remove PII residue

### Service Worker
- Versioned cache: `enote-` + `ENOTE_VERSION` (from build-config.js)
- Install: `fetch({cache:'reload'})` bypasses HTTP cache for fresh content
- `skipWaiting()` + `clientsClaim()` on install
- Stale-while-revalidate for navigation
- `controllerchange` listener in `index.html` auto-reloads on new SW activation
- `_sw_reloading` flag in sessionStorage prevents infinite reload loop; cleared in `init()`

### Conflict detection
- `updateNote` receives `_localModifiedEn` from `editingNoteModifiedEn`
- If server's `modificadoEn` is newer → `{ conflict, serverNote }` → `renderConflictView`
- Overwrite button re-calls with `_force: true`; keep-server button discards local changes

### Template conventions
- All HTML as template strings, no JSX
- All user input escaped via `esc()` (includes `'` → `&#39;`)
- Dates: ISO in store, `es-MX` in UI, `formatFecha()` uses UTC to prevent timezone day shift
- Falsy-safe: `pastelCantidad`/`pisos` use `!= null` not `||` defaults

### Blob URL lifecycle
- URLs created by `compressImage` tracked in `_blobUrls` array
- `revokeBlobUrls()` in `closeModal()` runs before DOM clear
- `showImagePreview` also tracks preview blob URLs

### CSP
- No external CDNs allowed (`script-src`, `style-src`, `font-src` all `'self'`)
- Fonts self-hosted in `assets/fonts/`
- Supabase JS client vendored in `js/vendor/`

### Cache rules (vercel.json)
- `/js/supabase.js` → `Cache-Control: no-cache, must-revalidate` (generated config)
- Static versioned assets → `Cache-Control: public, max-age=31536000, immutable`

## Testing

```bash
cd audit && npm install          # First time only
node audit-offline.js [URL]      # Offline suite (IndexedDB, queue, badge, fallback)
node audit-prod.js [URL]         # Production suite (3 roles, CRUD, offline, PWA, a11y)
node audit-v2.js [URL]           # v2 suite (pasteleria, financiero, receipt, conflict)
node scripts/pw-verify.js [URL]  # PWA and config verification
```

**Note:** `audit/audit.js` is obsolete (used demo credentials, now removed).

## Adding users

1. Supabase → Authentication → Users → Add user
2. Copy UUID
3. SQL: `INSERT INTO profiles (id, username, role, destino) VALUES ('<uuid>', 'name', 'role', 'destino|null')`
